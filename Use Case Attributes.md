# Use Case Attributes

1. Use Case is Repeatable
2. To solve the problem, there are a low in number of turns where new input must be gathered
3. The use case has a clear resolution path which is also bounded
4. Solution process is bounded
5. Solution set is constrained
6. Input data is quantifiable
7. There is a High volume of input data
8. input data is Non-destructive
9. Inputs and Outputs can form a fast loop
10. Input data is fresh, structured and consistent (i.e. not conflicting)
11. Policy and Rules are exact and easy to follow
12. Input data is multi-source
13. Agent Can Easily self-navigate a stable environment that is well understood
14. Agent Can Iterate
15. Agent Can Check (verify) results (i.e. results are decidable)
16. Agent Can Review logs of existing tests and results
17. Operator can "manage" the agent's memory
18. If sub-agents are used, there is strong goal alignment and cross-agent coordination
19. Speed to solution and volume of use cases are high priorities
20. Agent Can Pass exceptions to a human
